NODEWORKS — COMPLETE ASSET PACK 01–42

Berisi seluruh 42 aset yang sudah dibuat dalam percakapan ini.
Setiap folder mempertahankan isi paket individual: GLB, preview,
sumber pembuatan, README, dan hasil validasi yang tersedia.
Daftar file utama tersedia di asset-index.csv.

Aset tetap terpisah; paket ini tidak menggabungkan semuanya menjadi
satu scene ruangan. Dua folder karakter bekerja juga menyertakan GLB
kursi sebagai dependensi sumber. Itu bukan aset tambahan dalam daftar.

Model mengikuti referensi sebagai rekonstruksi, belum persis 1:1.
Model dan karakter statis tanpa rig/animasi. Wordmark logo menggunakan
font pendekatan. Baca README setiap aset untuk detail dan batasannya.

Seluruh 42 GLB utama diperiksa header glTF 2.0 dan panjang binernya.
Seluruh arsip individual dan paket gabungan lolos pemeriksaan CRC ZIP.
