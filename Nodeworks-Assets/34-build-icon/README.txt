Nodeworks — Asset 34: Build Icon

Rekonstruksi 3D berdasarkan gambar referensi, belum persis 1:1.
Panel putih persegi dengan sudut membulat dan bevel. Simbol kode </>
berwarna biru terdiri dari bracket kiri, slash tengah dan bracket kanan.
Simbol merupakan geometri ekstrusi dengan ujung membulat, bukan tekstur.

Format GLB / glTF 2.0, Y-up, unit meter, origin bottom-center.
Bagian depan menghadap -Z pada koordinat glTF.
Dimensi X/Y/Z: sekitar 0.180 x 0.180 x 0.025 m.
4 mesh; 988 segitiga; ukuran GLB 56,184 byte.
Material PBR tertanam; tanpa tekstur atau dependensi eksternal.
Model statis tanpa rig/animasi. Komponen diberi nama di dalam GLB.

Isi: GLB, preview render dari GLB aktual, build_build_icon.py,
render_preview.py, validation.json dan README.txt.
Build memerlukan Python, numpy, trimesh, shapely dan triangle.
Render memerlukan pyrender, PyOpenGL, Pillow dan OpenGL/EGL.
Jalankan skrip dari folder paket.
