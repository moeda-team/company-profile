Nodeworks — Asset 22: Laptop (Code)

Rekonstruksi 3D berdasarkan gambar referensi, belum persis 1:1.
Laptop terpisah: bodi abu gelap, bingkai layar graphite, keyboard,
trackpad, engsel, webcam, layar navy dengan garis kode putih/cyan
serta indikator pink. Garis kode adalah dekorasi geometris.

Format GLB / glTF 2.0, Y-up, unit meter, origin bottom-center.
Dimensi X/Y/Z: sekitar 0.340 x 0.225 x 0.273 m.
19 mesh; 9,040 segitiga; 163,764 byte.
Material PBR tertanam, tanpa tekstur atau dependensi eksternal.
Pose terbuka statis; tidak memiliki animasi buka-tutup atau rig.

Isi: GLB, preview render dari GLB aktual, build_laptop_code.py,
render_preview.py, validation.json dan README.txt.
Sumber build memerlukan Python, numpy dan trimesh.
Preview memerlukan pyrender, PyOpenGL, Pillow dan OpenGL/EGL.
Jalankan skrip dari folder paket.
