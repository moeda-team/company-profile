Nodeworks — Asset 25: Document Box

Rekonstruksi 3D berdasarkan gambar referensi, belum persis 1:1.
Empat map/binder berdiri: biru, putih, putih, biru. Tiap binder memiliki
cover terpisah, blok halaman, punggung dan lubang tarik cekung dengan
bagian dalam gelap. Binder biru memiliki label kecil; sisi luar binder
pertama memiliki label putih. Komponen diberi nama di dalam GLB.

Format GLB / glTF 2.0, Y-up, unit meter, origin bottom-center.
Dimensi X/Y/Z: sekitar 0.313 x 0.334 x 0.231 m.
29 mesh; 13,144 segitiga; ukuran GLB 364,992 byte.
Material PBR tertanam; tanpa tekstur atau dependensi eksternal.
Model statis tanpa rig/animasi. Halaman merupakan blok sederhana.

Isi: GLB, preview render dari GLB aktual, build_document_box.py,
render_preview.py, validation.json dan README.txt.
Build memerlukan Python, numpy, trimesh dan manifold3d.
Render memerlukan pyrender, PyOpenGL, Pillow dan OpenGL/EGL.
Jalankan skrip dari folder paket.
