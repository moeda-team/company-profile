Nodeworks - Asset 42: Logo (Nodeworks)

Rekonstruksi 3D berdasarkan gambar referensi, belum persis 1:1.
Logo terdiri dari emblem persegi biru bersudut membulat, simbol enam
cabang putih dan tulisan Nodeworks berwarna navy. Seluruh bagian berupa
geometri 3D, termasuk tulisan, bukan gambar tekstur.

Font asli tidak tersedia. Wordmark memakai DejaVu Sans Bold dengan
penyesuaian lebar agar mendekati proporsi referensi; bukan outline logo asli.
Font dan lisensinya disertakan untuk membangun ulang sumber. GLB tidak
memerlukan file font pada saat ditampilkan.

Format GLB / glTF 2.0, Y-up, unit meter, origin bottom-center.
Bagian depan menghadap -Z pada koordinat glTF.
Dimensi X/Y/Z: sekitar 0.676 x 0.180 x 0.022 m.
3 mesh; 3,304 segitiga; ukuran GLB 252,192 byte.
Material PBR tertanam; tanpa tekstur atau dependensi eksternal saat dibuka.
Model statis tanpa rig/animasi. Komponen diberi nama di dalam GLB.

Isi: GLB, preview render dari GLB aktual, build_nodeworks_logo.py,
render_preview.py, validation.json, font, lisensi font dan README.txt.
Build memerlukan Python, numpy, trimesh, shapely, triangle dan matplotlib.
Render memerlukan pyrender, PyOpenGL, Pillow dan OpenGL/EGL.
Jalankan skrip dari folder paket.
